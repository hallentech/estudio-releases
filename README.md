# Estúdio: pacotes

Só os pacotes do Estúdio (app do Mac da Hallen Tech para produzir vídeos com o Claude Code): o `.dmg` para instalar e,
em cada release, o pacote da atualização automática (`.app.tar.gz` assinado e `latest.json`), de onde os apps
instalados baixam a versão nova. O código-fonte não fica aqui.

Instalar: baixe o `.dmg` da release mais nova, arraste o Estúdio para Aplicativos e, na primeira vez, abra pelo botão
direito → Abrir. Depois disso, as versões novas aparecem em Ajustes → Sistema → "Versão nova".
